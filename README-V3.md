# L'Écho V3 — architecture centralisée

Le site ne sépare plus Bretagne et Lorraine en pages distinctes.
Le royaume est une propriété de chaque article.

- `index.html` : Articles
- `article.html?id=...` : article
- `archives.html` : archives
- `carte.html` : carte interactive conservée
- `articles.json` : catalogue éditorial
- `app.js` : date RP, articles, recherche, feuilles, thème
- `site.css` : style unique
