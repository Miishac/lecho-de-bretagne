# L'Écho de Bretagne et Lorraine

Bienvenue dans le dépôt de **L'Écho** — un journal libre et indépendant dédié aux terres de Bretagne et Lorraine dans l'univers des Royaumes Renaissants.

## 📖 À propos

L'Écho raconte les histoires, chroniques, et récits des terres de Bretagne et Lorraine. Chaque édition capture les moments, les personnages et les événements qui façonnent ces régions.

### Mission

- **Raconter** les terres et ceux qui les habitent
- **Conserver** la mémoire des histoires locales
- **Partager** les perspectives uniques de chaque communauté
- **Rester libre** et indépendant

## 🔧 Fonctionnalités techniques

### Service Worker
Permet de consulter le site hors ligne. Les pages visitées sont mises en cache.

### Dark Mode
Basculez entre le thème clair et sombre. Votre préférence est sauvegardée localement.

### Recherche
Recherchez dans tous les articles avec la barre de recherche principale.

### PWA
Installez le site comme une application sur votre téléphone ou tablette.
